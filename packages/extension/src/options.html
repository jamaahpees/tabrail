TabRail

Connect Chrome to a local MCP server.

Checking

Bridge

Default is 51337. Change it only if the MCP server uses MCP_BROWSER_PORT.

The MCP server writes this token to the user config folder on first run. The extension and the server must use the same value.

Allowed origins

Leave empty to allow every http and https page. Chrome system pages are always blocked.
